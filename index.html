PRINTDLE

Guess today's wide-format printer. New puzzle every day.

How to play

  • Type a printer model name and select it from the list.
  • Each guess reveals how close you are across 5 attributes.
  • Green — exact match.
  • Yellow — close but not exact (width range only).
  • Red — no match.
  • For print width, an arrow (↑ ↓) shows which direction to go.
  • You have 6 guesses. A new printer is chosen each day.
